## ✨ 排行概览

这个项目用于集中整理面向国内用户的 GPT API 中转服务信息，方便对比**站点入口、标示倍率及号池类型**，并为后续公开、可复现的测试提供统一入口。

- **收录数量：**150 个站点（来自初始名单，尚未逐站核实）
- **展示方式：**六个等级，保留原始排名；每组可展开查看
- **最近整理：**2026-11-17（非站点在线状态检查日期）
- **数据范围：**站点名称 / 官网 / 原始标示倍率 / 原始标示号池类型
